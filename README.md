# Veronika Albero — сайт

Статический сайт: один самодостаточный файл.

## Файлы
- `index.html` — весь сайт (скрипты, стили, фоновое фото внутри)

## Деплой на Vercel
1. Загрузите содержимое этой папки в корень репозитория (`index.html` — в корне).
2. В Vercel: Add New → Project → выберите репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми (Root Directory — корень).
4. Deploy.

Либо без репозитория: `npx vercel deploy --prod` из этой папки.

## Домен
Vercel → Project → Settings → Domains → Add, далее по инструкции DNS.

## Фото
Фотографии, перетянутые в слоты в редакторе, хранятся в браузере и в этот файл не попадают.
Чтобы они были на публичном сайте, положите файлы рядом (например `photos/portrait.jpg`)
и пропишите их в слотах атрибутом `src`.
